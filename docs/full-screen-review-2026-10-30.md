# 전체 화면·홈 제목 점검 (2026-10-30)

## 목표와 완료 조건

홈 카드의 실제 글자가 같은 Pretendard, 18px, 굵기 600, 줄높이 1.4를 사용한다. Maps(기업/ETF), Daily Market Briefing, Latest News, Calendar, Market Movers, Yahoo Finance Live를 포함한다. 좁은 화면과 브리핑 상세를 방문한 뒤에도 유지한다. 주요 페이지는 제목 하나와 본문이 표시되고 문서 전체가 가로로 넘치지 않아야 한다.

금융 값·단위·기간·기준 시각·원문 출처·승인된 기사·저장 기록은 보존한다. 이번 작업은 공통 제목, 과거 브리핑 호환, 전체 캘린더 제목 구조와 회귀 검사에 한정한다.

## 운영에서 발견한 사항

변경 전 운영 사이트를 데스크톱 브라우저로 직접 열어 확인했다. 홈 제목의 글꼴 계열은 이미 Pretendard였지만 브리핑은 14px/650, 뉴스는 19px/600, Maps는 18px/400, 나머지 보조 카드는 18px/600이었다. 제목 안 링크에도 같은 스타일을 적용해야 했다.

2026-10-16 브리핑은 과거 자료에 `corrections`가 없어 페이지와 근거 생성 경로가 실패했다. 정정 이력이 선택적인 과거 형식을 타입과 소비 지점에서 처리한다. 원본 기사에 빈 정정을 삽입하지 않는다. 실제 게시된 25편 모두의 제목·요약 개수·출처 URL과 근거 시각을 회귀 검사한다.

전체 캘린더는 페이지 제목이 h2였다. 전체 화면에서는 h1, 홈 카드에서는 h2를 사용하되 기존 모양을 유지한다.

홈 최신 브리핑 생성물이 원본 승인 기사보다 하루 이전이었다. 기존 생성기를 실행해 `latest-briefing.json`을 현재 승인 원본과 동기화했다. 기존 동일성 검사가 이 불일치를 검출했으며 원본 승인 내용은 수정하지 않았다.

운영 20개 경로(아래 검사 목록 중 과거 브리핑 포함)를 열었다. 과거 브리핑의 실패와 캘린더 h1 누락 외에 초기 표시에서 문서 가로 넘침은 발견하지 못했다. 이 관찰은 모든 외부 데이터의 정확성이나 모든 조작의 성공을 보장하지 않는다. 운영 저장 기록은 수정하지 않았다.

## 검사 설계

- `screen-review.spec.mjs`: 홈, 시장, 주식, 금리, 연준, 경제지표, 매크로, 전체 캘린더, 공시 모니터, 13F, 시뮬레이터, 저장 목록, 투자 노트, 브리핑 목록·최신·과거·작성 원칙, 더보기, Live, AAPL 상세 등 20개 화면. 데스크톱 프로젝트 1440/768px, 모바일 프로젝트 393/320px에서 총 80개 렌더를 확인하고 전체 화면 PNG와 제목 측정 JSON을 보관한다. h1·준비된 본문·문서 넘침·제목 잘림·모바일 현재 메뉴·런타임 예외를 확인한다.
- `home-ui.spec.mjs`: 1440/1024/768/393/320px, 기업/ETF Maps 전환, 브리핑 상세 방문 후 귀환 시 실제 제목과 링크의 계산 스타일을 확인한다. 모바일은 기존 구성대로 일부 카드가 표시되지 않는다.
- 기존 검색·차트·저장/복원·근거·13F·시뮬레이터·공시·거래일 검사도 전체 실행한다.
- `briefing-archive-ui.test.mjs`: 실제 게시된 25편의 SSR과 근거 생성을 확인한다.

브라우저 자동 검사는 외부 제공자 변동과 호출량을 피하기 위해 합성 응답을 사용한다. 시세 정확성·실시간 API 가용성 검사가 아니다. 운영 관찰은 실제 응답을 사용하며 모바일/태블릿은 CI Chromium 에뮬레이션이다. 실제 기기와 Safari는 미검증이다. 로컬에는 Chromium이 없어 브라우저 검사는 GitHub CI에서 실행한다.

검사 SHA·CI 링크·독립 리뷰·미리보기 상태는 PR 검증 표에 기록한다. 새 변경의 main 병합과 운영 반영은 별도 요청 후 진행한다. 기존 초기 JS 예산과 소스 그래프 검사를 유지한다.
