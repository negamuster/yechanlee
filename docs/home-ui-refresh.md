# Home UI refresh, phase 1

Goal: make Anthracite easier to scan through readable Korean/Latin typography, a clear visual hierarchy, consistent controls/icons, and responsive spacing. Keep the existing menu order, widget destinations, filters, keyboard/focus behavior, data provenance/units/dates, unavailable/stale states, and local user records. This phase does not change financial calculations or provider requests.

Use pinned Pretendard 1.3.9 (local npm-served variable dynamic subsets) and lucide-react 1.63.0 (named icon imports only). Adapt the simple Card/Skeleton source patterns from shadcn/ui revision 96da9cc7f1aa10580a3741664e2a77c721206c00 to existing CSS tokens instead of installing a second interactive primitive system. Include upstream licenses/notices. Font files are emitted as local Vite assets; no font CDN is required at runtime. Measure the emitted CSS/font/JS cost separately; a typeface is not a free performance improvement.

Direction: neutral page background, white cards, blue selected/action/focus states, dark readable text, 15px body / 14px controls / 13px metadata / 12px captions, 8px-based spacing, 20px card corners. Preserve existing financial up/down color meanings and use text/signs alongside colors. Keep every failure/previous-data warning and its timestamp visible; decoration must not become a second accessible label.

Home keeps the current briefing, news, Maps, calendar, movers and live destinations. Add a single home h1, make briefing/news headlines use the same UI typeface, soften heavy newspaper borders, and give all cards consistent padding/controls. Large screens keep the familiar three areas; intermediate screens have two areas and narrow screens prioritize the reading column. Mobile retains its current dedicated briefing/news flow and bottom navigation. No new startup API calls or autoplay policy changes are introduced in this phase.

Verification: reuse the full Node/lint/build and desktop/Pixel7 Chromium suite; add focused checks for local font loading, readable control/caption sizes, no horizontal overflow at narrow/tablet/desktop widths and 200% zoom equivalent, icon accessibility, independent widget controls, unchanged save/filters/modal focus, and source-error visibility. Capture deterministic desktop/mobile home screenshots from CI for visual review. Independent review is required by AGENTS.md. Actual mobile devices/Safari and Vercel-protected preview access must be reported separately. PR/CI is the current delivery scope; main merge/production remains a separate explicit request.
