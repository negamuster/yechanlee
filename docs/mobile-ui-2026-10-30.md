# 모바일 UI 정리

## 목표와 완료 조건

shadcn/ui의 Card·Button·Empty·Sheet 구성 방식을 참고해 기존 모바일 홈과 뉴스 필터의 정보 위계, 버튼 역할, 선택 상태를 정리한다. 1단계는 현재 Pretendard·Lucide·색상 토큰으로 정리하고, 2단계는 스와이프 닫기를 위해 Base UI Drawer 한 곳을 적용한다. 원본 컴포넌트 코드를 복제하지 않는다.

- 320·393·700px에서 홈의 가로 넘침 없이 뉴스 본문 너비를 확보한다. PC 구성과 공통 제목 규격은 유지한다.
- 브리핑 요약 3개와 출처·기준 시각·주의 문구를 그대로 표시하고 전체 보기 링크를 명확히 한다.
- 필터 조건은 적용 전 초안으로 유지한다. 닫기/Escape/배경 클릭은 취소하고 적용·초기화·새로고침·재진입은 기존 의미를 유지한다.
- 선택은 색상과 체크 표시로 구분한다. 필터 선택 영역·버튼은 최소 44px이며 키보드 포커스가 보이고 닫은 뒤 트리거로 돌아온다.
- 빈 검색 결과와 수집 실패·부분 실패·이전 기사 상태를 구분해 표시한다.

## 범위와 데이터 규칙

모바일 홈 CSS, 브리핑 CTA, 뉴스 필터·빈 상태 표현만 바꾼다. API, 정렬·필터링 로직, 저장 키/스키마, 사용자 기록, 금융 값/기간/출처는 바꾸지 않는다. Base UI만 정확 버전으로 추가하며 드로어는 지연 로딩해 초기 JavaScript 예산을 유지한다.

## 검증

기존 Node 회귀 검사·lint·빌드·초기 JS 예산 검사와 PC/모바일 Chromium 전체 CI를 재사용한다. 홈 UI 검사에 320/393/700px의 필터 적용·취소·초기화·선택 표시·스크롤 가능한 본문·화면 내 푸터·가로 넘침·포커스 복귀와 화면 증거를 추가한다. 중요한 모바일 흐름 변경이므로 구현자와 별도 리뷰를 수행하고 PR에 SHA와 결과를 적는다. 실제 iOS/Safari 검증은 별도로 구분한다.

## 2단계: Base UI Drawer

`@base-ui/react` 1.9.0의 Drawer를 뉴스 필터 한 곳에 적용한다. 상단 손잡이/헤더의 아래 방향 드래그로 취소하고, 본문과 푸터는 swipe-ignore로 보호해 네이티브 스크롤·조건 변경과 충돌하지 않게 한다. 적용/초기화 의미는 유지한다. Drawer는 동적 import하고 네이티브 로딩·실패 dialog를 제공한다. 초기 요청에서 제외, 로딩 중 취소, 실패 후 새로고침 복구, 실제 touch 입력/마우스 드래그, 본문 스크롤·Escape·외부 클릭·포커스 복귀를 Chromium에서 검사한다. Ctrl+K는 열려 있는 modal을 존중한다. 네이티브 dialog 내부 구조에 의존하던 SSR 검사는 실제 portal의 브라우저 검사로 옮긴다.

참고: [Drawer](https://base-ui.com/react/components/drawer), [Portal/Safari 설정](https://base-ui.com/react/overview/quick-start).

## 3·4단계 적용 판단

뉴스 필터의 radio·checkbox는 이미 네이티브 접근성 의미와 키보드 조작을 갖추고 있어 React Aria로 교체할 필요가 없다. 동일 책임을 Base UI와 중복 설치하지 않는다. 기존 검색/근거 연결은 네이티브 modal이며 뉴스 필터와 동시에 여는 경로는 검색 단축키 차단으로 처리한다. 현재 단일 초안/확인 흐름에는 overlay-kit을 추가하지 않는다. 복잡한 중첩 흐름이 생기면 별도로 도입한다.

## 이후 순서

이번 단계의 확인 가능한 필요는 스와이프 닫기이며 스냅 포인트는 추가하지 않는다. 입력에는 React Aria를, 중첩 오버레이에는 overlay-kit을 필요에 따라 선택한다. 서로 겹치는 구현을 한꺼번에 설치하지 않는다.

참고: [shadcn/ui Button](https://ui.shadcn.com/docs/components/base/button), [Empty](https://ui.shadcn.com/docs/components/base/empty), [Sheet](https://ui.shadcn.com/docs/components/base/sheet).
